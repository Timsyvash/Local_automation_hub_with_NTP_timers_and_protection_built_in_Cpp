# Local Automation Hub with NTP Timers and Protection in C++ (ESP8266)

Цей проєкт реалізує захищений локальний хаб автоматизації на базі мікроконтролера **Wemos D1 mini (ESP8266)**. Система забезпечує точну синхронізацію часу через інтернет за протоколом **NTP** без використання апаратних годинників реального часу (RTC), захищений доступ до вебпанелі за допомогою **HTTP Basic Authentication**, а також працює на повністю неблокуючій архітектурі автоматів станів (FSM) із захистом від зависань та перезавантаженням сторожовим таймером (Watchdog Timer).

---

## 🚀 Основні можливості

* **Неблокуюча архітектура (Finite State Machine - FSM)**: Розподіл логіки на стани (`CONNECTING`, `RUNNING`, `NOT_CONNECTED`) із використанням функції `millis()`, що запобігає спрацьовуванню WDT-ресетів і зависанням.
* **Синхронізація точного часу (NTP)**: Отримання часу з глобальних серверів точного часу (`pool.ntp.org`) з урахуванням локального часового поясу.
* **Захист вебпанелі (HTTP Basic Authentication)**: Обмеження доступу до вебсервера за допомогою логіна та пароля.
* **Автоматизація за розкладом (NTP Timers)**: Виконання завдань та подій за точним часом (години, хвилини, секунди) безпосередньо в коді C++.
* **Автоматичне відновлення зв'язку**: 
  * Контроль підключення до Wi-Fi з обмеженням часу очікування (30 секунд) та безпечним перезавантаженням (`ESP.restart()`) у разі збою.
  * Автоматичне перепідключення (`WiFi.reconnect()`) у випадку тимчасової втрати сигналу.
* **Підтримка mDNS**: Доступ до пристрою в локальній мережі за зручною адресою `http://esp8266.local`.

## 🛠 Апаратне забезпечення та залежності

* **Мікроконтролер**: Wemos D1 mini (ESP8266)
* **Середовище розробки**: VS Code + PlatformIO
* **Фреймворк**: Arduino

### Залежності (`platformio.ini`)
Для роботи проєкту необхідні такі бібліотеки:
```ini
[env:wemos_d1_mini]
platform = espressif8266
board = d1_mini
framework = arduino
monitor_speed = 115200
lib_deps =
    taranais/NTPClient @ ^3.2.1
